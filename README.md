# Bleuolingo

A minimalist flashcard web app using Free Spaced Repetition Scheduler algorithm.

- UI flicker when changing cards
- Bleuolingo speech bubble is outside viewport
- Poor placement / UI for audio language change

## Feature requests, highest to lowest priority
