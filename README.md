# Bleuolingo

A minimalist flashcard web app for language learning using the Free Spaced Repetition Scheduler algorithm.

## Known issues, highest to lowest priority
- Bleuolingo speech bubble is outside viewport
- Poor placement / UI for audio language change
- App logo is missing blue-colored sections of bleuo
- Recall rate in "session complete" UI always says good even for low percentages

## Feature requests, highest to lowest priority
